# 📚 Related Work Context

EndSurvGAN is positioned at the intersection of three research areas:

## 1. Synthetic Tabular Data Generation

Traditional generative models focus mainly on feature distribution preservation. However, survival datasets contain additional structures such as censoring and time-to-event dependencies.

## 2. Generative Modeling for Healthcare Data

Healthcare synthetic data generation requires balancing:

- Data utility
- Privacy preservation
- Clinical realism
- Statistical validity

## 3. Survival Analysis

Unlike standard prediction tasks, survival modeling requires handling:

- Right censoring
- Time-dependent outcomes
- Event processes

EndSurvGAN aims to combine these perspectives into a unified survival-aware generative framework.
